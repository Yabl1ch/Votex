# Поэтапный план реализации Votex (Roadmap)

**Проект:** Votex (Антицензурный автоматизированный VPN-менеджер и провизионер VPS)  
**Репозиторий:** [github.com/Yabl1ch/Votex](https://github.com/Yabl1ch/Votex)  
**Архитектурный стандарт:** Autonomous Development Pipeline (ADP) & `organic-glass-bento-ui`  
**Формат исполнения:** Каждая фаза выполняется в отдельной сессии чата с фиксацией в Git и обязательным обновлением `README.md`.

## Фаза 1: Серверный монолит и инфраструктурный харднинг (Backend VPS)

### Цель чата:
Завершить и протестировать автономный bash-скрипт `scripts/votex-install.sh`, выполняющий за один проход харднинг ОС, установку VPN-ядра (Xray + Hysteria 2), генерацию ключей, бенчмарк и запуск службы подписки.

### Задачи:
1. **Скрипт `scripts/votex-install.sh`**:
   - Pre-flight проверки (root, архитектура `amd64`/`arm64`, определение внешнего IP).
   - Харднинг ядра Linux (`/etc/sysctl.d/99-votex.conf`: TCP BBR, SYN Cookies, буферы).
   - Защита от брутфорса Fail2ban (джейл `sshd` на порту 22, бан 24 часа за 4 ошибки).
   - Фаервол UFW (закрытие лишних портов, открытие 22, 20443, 2053, 8443, 2083, 2088, 18080).
2. **Мультипротокольный стек All-in-One**:
   - Установка официального Xray-core и Hysteria 2.
   - Генерация ключей X25519 (`xray x25519`), `shortId`, UUID клиента и паролей.
   - Inbounds: Reality Vision (20443), SplitHTTP xhttp (2053), gRPC (8443), Hysteria 2 (2083), Shadowsocks-2022 (2088).
   - Маскировка под `addons.mozilla.org`.
3. **Микросервис подписки `votex-subscription`**:
   - Python 3 демон на порту 18080 со скрытым токеном `/sub/{TOKEN}`.
   - Динамическая выдача Base64-подписки и JSON-профиля со Smart Routing (Direct для РФ, Proxy для ИИ и зарубежных сайтов, Block для рекламы и торрентов) и TLS-фрагментацией.
4. **Бенчмарк и отчет**:
   - Замер пинга до Cloudflare/Google и тест скорости скачивания через CDN.
   - Генерация структурированного JSON-отчета `/var/log/votex-report.json`.

### Обязательные действия агента в конце Фазы 1:

## Фаза 2: Инициализация ядра Tauri v2 и нативного SSH-модуля (Rust Core)

### Цель чата:
Развернуть окружение Tauri v2 с бэкендом на Rust, реализовать нативный асинхронный модуль подключения по SSH и настроить потоковую передачу терминального вывода в окно приложения.

### Задачи:
1. **Инициализация проекта Tauri v2**:
   - Настройка манифеста `src-tauri/Cargo.toml` с зависимостями: `tauri`, `russh` (или `ssh2`), `tokio`, `serde`, `serde_json`, `ring`, `reqwest`.
   - Конфигурация `src-tauri/tauri.conf.json` (прозрачность стекла, кастомный заголовок окна, минимальные размеры 960x640).
2. **Нативный SSH-провизионер (`src-tauri/src/commands/ssh.rs`)**:
   - Команда `run_provisioning(host, port, user, password)`: подключение к серверу, передача и запуск `votex-install.sh`.
   - Потоковая трансляция строк лога в реальном времени через события Tauri (`emit("ssh-log", line)`).
   - Захват и парсинг финального блока `VOTEX_JSON_REPORT_START` ... `VOTEX_JSON_REPORT_END`.
3. **Безопасное хранилище (`src-tauri/src/vault.rs`)**:
   - Локальное шифрование учетных данных сервера (IP, порт, токен подписки) с помощью AES-GCM.
4. **Команды управления сервером**:
   - `test_connection(host, port)`: быстрый пинг порта 22.
   - `fetch_server_metrics(host)`: опрос статуса служб Xray, Hysteria 2 и Fail2ban.

## Фаза 3: Фронтенд и дизайн-система `organic-glass-bento-ui` (React + TypeScript)

### Цель чата:
Создать пользовательский интерфейс приложения на React 19 + TypeScript в строгом соответствии с фирменной дизайн-системой `organic-glass-bento-ui`.

### Задачи:
1. **Настройка фронтенд-инфраструктуры**:
   - Vite + React 19 + TypeScript + Tailwind CSS v4 + Framer Motion + Zustand.
   - Реализация CSS-токенов дизайн-системы:
     - Точечный фон Dot-Matrix (`background-size: 22px 22px`).
     - Матовое стекло `backdrop-filter: blur(24px) saturate(160%)`.
     - Палитра: обсидиановый фон `#06100C`, изумрудный акцент `#22C55E`, мятный `#4ADE80`.
     - Грани со световым бликом `inset 0 1px 1px 0 rgba(255, 255, 255, 0.12)`.
2. **Базовые Bento-компоненты**:
   - `BentoCard`: парящий изолированный блок с радиусом скругления и мягким свечением.
   - `BentoGrid`: модульная сетка с отступами `16px–24px` и шагом `gap: 16px–20px`.
   - `GlassButton`: пружинная кнопка со spring-анимацией (`stiffness: 320, damping: 26`).
   - `GlassInput`: поле ввода с мягкой подсветкой фокуса.
   - `TerminalView`: эмулятор терминала со стеклянной подложкой, автопрокруткой и подсветкой синтаксиса.
3. **Векторная иконографика (SVG)**:
   - Полный набор чистых векторных SVG-иконок (Shield, Server, Terminal, Copy, Check, Refresh, Zap, Activity, Lock, ExternalLink).
   - Строгий запрет на Unicode-эмодзи в UI.
