## Что такое Votex

Votex — это простое настольное приложение для Windows, которое самостоятельно подключается к вашему чистому виртуальному серверу (VPS) и полностью настраивает современную, быструю и устойчивую к блокировкам VPN-сеть.

Вам не нужно разбираться в администрировании Linux, прописывать команды в консоли или вручную настраивать сертификаты шифрования. Достаточно ввести IP-адрес и пароль от купленного сервера — программа сделает всё сама за пару минут.

## Преимущества

- **Умное разделение сайтов (Smart Routing)**:
  - Российские сервисы, банки (Сбербанк, Т-Банк, ВТБ), Госуслуги, Ozon, Wildberries, Кинопоиск и сайты зоны `.ru` открываются напрямую через вашего интернет-провайдера. Они работают на полной домашней скорости, не зависают и не требуют отключения VPN.
  - YouTube в 4K, Discord, заблокированные сайты, международные сервисы и нейросети (ChatGPT, Claude, Gemini) открываются мгновенно через защищенный туннель.
  - Реклама, фишинг и вредоносные трекеры блокируются автоматически.
- **5 современных протоколов**: если провайдер начнет замедлять или ограничивать один из типов подключения, у вас всегда остаются надежные альтернативные каналы.
- **Встроенная защита сервера**: система автоматически настраивает межсетевой экран и блокирует ботов, сканеры и попытки подбора паролей.
- **Легковесность и автономность**: программа запускается без установки сторонних компонентов, не требует правки системных драйверов и потребляет минимум оперативной памяти (~15 МБ).

## Быстрый старт: 3 простых шага

### Шаг 1. Скачайте приложение
Загрузите готовый файл [`votex.exe`](https://github.com/Yabl1ch/Votex/releases/latest/download/votex.exe) (или [портативный ZIP-архив](https://github.com/Yabl1ch/Votex/releases/latest/download/Votex_1.0.0_portable.zip)). Установка в операционную систему не требуется — просто запустите скачанный файл.

### Шаг 2. Введите данные вашего сервера
В открывшемся окне Votex перейдите на вкладку **«Мастер установки»**:
- Укажите **IP-адрес** вашего сервера.
- Укажите **пароль root** (приходит на почту при покупке VPS).
- Нажмите кнопку **«Настроить и защитить сервер»**.

Программа сама подключится к серверу, установит все компоненты, настроит защиту и проверит скорость.

### Шаг 3. Подключитесь на телефоне или компьютере
После завершения настройки нажмите кнопку **«Копировать ссылку для Happ»** либо отсканируйте QR-код камерой смартфона.

Вставьте ссылку в бесплатное приложение-клиент:
- **iPhone / iPad:** Happ, Streisand, sing-box
- **Android:** Happ, v2rayNG, sing-box
- **Windows / macOS:** Happ, v2rayN, sing-box

Все протоколы с раздельной маршрутизацией подключатся автоматически.

Votex разворачивает на сервере полный набор актуальных протоколов нового поколения с высокой пропускной способностью и низкой задержкой:

| **VLESS SplitHTTP** | Продвинутая маскировка трафика для обхода жестких фильтров и ограничений провайдеров | До 350+ Мбит/с | 35–45 мс |

| **Shadowsocks-2022** | Проверенный временем и надежный резервный протокол шифрования | До 400+ Мбит/с | 30–38 мс |

## Какой сервер подойдет

Для работы Votex подходит практически любой виртуальный сервер (VPS):
- **Операционная система:** чистая Ubuntu (22.04 или 24.04) либо Debian (11 или 12).
- **Минимальные параметры:** 1 vCPU, 512 МБ RAM (рекомендуется 1 ГБ).
- Стоимость аренды такого сервера у большинства хостинг-провайдеров составляет от 150 до 300 рублей в месяц. Сервер находится полностью под вашим контролем.

## Сборка из исходников

Для разработчиков, желающих собрать проект самостоятельно:

```powershell
# Клонировать репозиторий
git clone https://github.com/Yabl1ch/Votex.git
cd Votex

# Установка зависимостей
pnpm install

# Запуск в режиме разработки
pnpm tauri dev

# Сборка релизного .exe файла
pnpm tauri build --no-bundle
```
