## Быстрый старт для пользователя (Quick Start Guide)

Votex спроектирован так, чтобы любой пользователь мог развернуть собственный защищенный сервер за 2 минуты без ручного ввода команд в Linux-консоли.

1. **Шаг 1: Скачать Votex**
   - Скачайте готовый автономный бинарник [`votex.exe`](https://github.com/Yabl1ch/Votex/releases/latest/download/votex.exe) или инсталлятор [`Votex_1.0.0_x64-setup.exe`](https://github.com/Yabl1ch/Votex/releases/latest) из раздела [Releases](https://github.com/Yabl1ch/Votex/releases/latest).
   - Приложение полностью независимо, не требует установки рантаймов (Node.js/Python) и весит ~13 МБ.

2. **Шаг 2: Ввести реквизиты купленного VPS**
   - Запустите `votex.exe`.
   - В открывшемся окне перейдите на экран **«Мастер установки»**.
   - Введите публичный IPv4-адрес чистого VPS (Ubuntu 22.04 / 24.04 или Debian 11 / 12) и пароль учетной записи `root`.
   - Нажмите акцентную кнопку **«Настроить и защитить сервер»**.

3. **Шаг 3: Автоматическое развертывание и харднинг**
   - Встроенный терминал в реальном времени отобразит выполнение полного цикла: настройку фаервола UFW, активацию джейла Fail2ban, включение TCP BBR, установку ядра Xray/Hysteria 2 и проведение бенчмарка.
   - По завершении на экране появится персональная зашифрованная ссылка подписки.

4. **Шаг 4: Импорт подписки в мобильный или ПК клиент**
   - Нажмите **«Копировать ссылку для Happ»** в 1 клик на Главной странице либо отсканируйте сгенерированный QR-код на экране **«Подписка»**.
   - Добавьте подписку в клиент:
     - **iOS / iPadOS:** Happ, Streisand, FoXray, sing-box.
     - **Android:** Happ, v2rayNG, sing-box.
     - **Windows / macOS / Linux:** Happ, v2rayN, sing-box, Nekoray.
   - Все 5 протоколов с автовыбором наилучшего канала, раздельной умной маршрутизацией (DIRECT для РФ, PROXY для мирового интернета и ИИ, BLOCK для рекламы) и TLS-фрагментацией работают сразу «из коробки».

## Архитектурные принципы

```
                    ПОЛЬЗОВАТЕЛЬСКИЙ ТРАФИК
                               │
                               ▼
                [ DNS-проверка и анализ домена ]
                               │
            ┌───────────────────┼───────────────────┐
            │                   │                   │
            ▼                   ▼                   ▼
     Сегмент РФ          Зарубежный веб / ИИ    Реклама и Мусор
    (.ru, Банки,          (YouTube, Discord,      (Apple Relay,
     Госуслуги)            Gemini, Claude)         BitTorrent)
            │                   │                   │
            ▼                   ▼                   ▼
       [ DIRECT ]          [ PROXY ]           [ BLOCK ]
    Напрямую без VPN    Мультипротокольный      Сброс соединения
    (Макс. скорость,      туннель VPS           (Защита от абуз,
     нет банов банков)   (Обход ТСПУ/DPI)        чистый трафик)
```

- **One-Click Hardening**: Тюнинг ядра Linux (TCP BBR + fq), защита от брутфорса Fail2ban, фаервол UFW с политикой default deny.
- **Мультипротокольный стек All-In-One**: VLESS Reality Vision, VLESS Reality SplitHTTP (xhttp), VLESS Reality gRPC, Hysteria 2 (UDP) и Shadowsocks-2022.
- **Smart Routing (Умная маршрутизация)**: Автоматическое разделение трафика:
  - Российские сервисы, банки и госсайты (`.ru`, `.su`, Yandex, VK, Ozon, Gosuslugi, Сбербанк, Т-Банк) идут напрямую (**Direct**).
  - Заблокированные ресурсы и ИИ-сервисы (Gemini, Claude, OpenAI, YouTube, Discord) идут через зашифрованный туннель (**Proxy**).
  - Реклама, трекеры и BitTorrent блокируются (**Block**).
- **TLS Client Fragmentation**: Фрагментация пакетов на уровне клиента (`packets: 1-3`, `length: 100-200`, `interval: 10-20ms`) для гарантированного обхода сигнатурного анализа ТСПУ/DPI.
- **Burst Observatory**: Клиентский механизм автоматического выбора наименее нагруженного и самого быстрого протокола с бесшовным переключением при попытке блокировки.
- **Легковесный десктоп**: Приложение на базе **Tauri v2 + Rust + React 19 / TypeScript** с фирменной дизайн-системой **organic-glass-bento-ui**.

## Подробное руководство пользователя по 6 экранам приложения

### 1. Экран «Мастер установки» (`ProvisioningPage`)
- **Валидация полей ввода**: строгая проверка IPv4 (октеты 0–255), диапазона SSH-порта (1–65535, по умолчанию 22) и непустого пароля `root`.
- **Проверка соединения**: кнопка «Проверить соединение» запускает быстрый асинхронный замер доступности целевого порта с выводом пинга до старта развертывания.
- **Потоковый терминал (TerminalView)**: при нажатии «Настроить и защитить сервер» запускается скрипт `votex-install.sh`. Вывод транслируется построчно в реальном времени с автопрокруткой и динамическим прогресс-баром от 0% до 100%.
- **Автоматический перехват отчета**: после завершения скрипта приложение перехватывает JSON-отчет, сохраняет его в Zustand Store и шифрует в локальный Vault, отображая карточку успеха с кнопками быстрого перехода на Главную, во вкладку Подписки или Отчётов.

### 2. Экран «Главная» (`DashboardPage`)
- **Индикатор статуса VPS**: визуализация состояния (Online/Offline, Uptime, публичный IP-адрес, локация сервера в Нидерландах).
- **Быстрая подписка**: акцентный модуль со ссылкой и кнопкой «Копировать ссылку для Happ» в 1 клик с пружинной анимацией подтверждения («Ссылка скопирована в буфер!»).
- **Виджет задержки (Ping)**: текущий пинг до сервера, индикация 0% потерь пакетов, мини-график стабильности (sparkline) за последние замеры и кнопка быстрого обновления через `run_quick_ping`.
- **Матрица протоколов**: сетка из 5 карточек независимых протоколов (VLESS Reality Vision, SplitHTTP, gRPC, Hysteria 2, Shadowsocks-2022) со статусами, портами и замеренными задержками.

### 3. Экран «Отчёты и бенчмарки» (`ReportsPage`)
- **Спидометр туннеля (SpeedGauge)**: наглядные круговые шкалы скоростей скачивания (Download) и отдачи (Upload) в Мбит/с.
- **Сравнение задержек протоколов (LatencyBar)**: горизонтальные сравнительные столбчатые графики времени трехстороннего рукопожатия (Handshake Latency) для всех 5 протоколов.
- **Метрики устойчивости к ТСПУ/DPI**: оценка надежности обхода блокировок (99.8%), джиттера (1.2 мс), потерь пакетов (0.0%) и готовности к 4K 60fps HDR видеопотоку.
- **Интерактивные действия**: кнопка «Повторить тест скорости» для мгновенного удаленного замера через сервер и кнопка «Экспорт отчета (JSON)» для скачивания полного файла конфигурации и бенчмарков.

### 4. Экран «Подписка и маршрутизация» (`SubscriptionPage`)
- **Генерация QR-кода**: интерактивный генератор QR-кода на базе библиотеки `qrcode` для быстрого добавления серверов в мобильные клиенты Happ (iOS/Android), v2rayNG или Streisand.
- **Безопасная перегенерация токена**: кнопка «Перегенерировать токен» выпускает новый 32-байтный криптографический ключ подписки в случае компрометации старой ссылки и обновляет Vault.
- **Инспектор правил Smart Routing**: 3 вкладки правил с поиском по доменам:
  - **DIRECT (Прямой доступ РФ)**: `.ru`, `.su`, Госуслуги, Сбербанк, Т-Банк, Альфа, ВТБ, Yandex, VK, Ozon, Wildberries, Авито, `geoip:ru`.
  - **PROXY (Защищенный туннель)**: YouTube, Discord, Google Gemini, Anthropic Claude, OpenAI ChatGPT, Instagram, X/Twitter, GitHub.
  - **BLOCK (Блокировка)**: реклама, трекеры, Apple Private Relay, BitTorrent протокол.
- **Индикатор TLS-фрагментации**: параметры сегментации ClientHello (`packets: 1-3`, `length: 100-200`) для скрытия SNI от систем DPI.

### 5. Экран «Безопасность и сервер» (`SecurityPage`)
- **Монитор Fail2ban**: счетчик отраженных брутфорс-атак на порт 22 за последние 24 часа, параметры джейла (bantime 24ч, maxretry 4).
- **Таблица заблокированных IP ботов**: интерактивный список атакующих IP-адресов с кодами стран, временными метками, причиной бана, поиском и кнопкой ручной разблокировки.
- **Матрица портов UFW**: визуальный контроль разрешенных портов (22, 20443, 2053, 8443, 2083, 2088, 18080) с гарантией блокировки всех остальных входящих портов (DEFAULT DROP).
- **Управление службами**: кнопки мягкого перезапуска Xray-core, перезапуска Hysteria 2 и кнопка перезагрузки VPS с защитным модальным окном подтверждения.

### 6. Экран «Настройки» (`SettingsPage`)
- **Фирменная дизайн-система**: переключение тем оформления `organic-glass-bento-ui` (Obsidian Deep Forest и Sage Glass).
- **Параметры соединения**: регулировка таймаута SSH (15, 30, 60 секунд) и переключатель автосохранения в Vault.
- **Защищенное хранилище (Vault)**: просмотр данных активного сохраненного сервера, кнопка безопасной очистки `.votex_vault.bin`.
- **Проверка обновлений**: интеграция с GitHub API для онлайн-проверки новых релизов и версий Votex.

## Архитектура нативного ядра Tauri v2 и Rust Core

Приложение Votex построено на базе гибридной архитектуры: легковесный веб-интерфейс на React 19 + TypeScript + Tailwind CSS v4 и высокопроизводительный системный бэкенд на Rust с фреймворком **Tauri v2**.

### Контракты IPC-команд Rust

| Команда Tauri IPC | Входные аргументы | Возвращаемое значение | Назначение |
|---|---|---|---|
| `run_provisioning` | `host`, `port`, `username`, `password` | `Result<VotexReport, String>` | Асинхронное подключение по SSH, выполнение `votex-install.sh`, потоковая трансляция логов через событие `ssh-log`, парсинг и сохранение отчета в Vault |
| `test_connection` | `host`, `port` | `Result<ConnectionTestResult, String>` | Быстрый асинхронный TCP-пинг порта 22 с замером задержки рукопожатия до старта настройки |
| `fetch_server_metrics`| `host` | `Result<ServerMetrics, String>` | Опрос доступности портов SSH (22), подписки (18080) и Reality (20443) |
| `get_saved_vps` | — | `Result<Option<VaultRecord>, String>` | Извлечение расшифрованных учетных данных последней успешной конфигурации из Vault |
| `save_saved_vps` | `record: VaultRecord` | `Result<(), String>` | Принудительное зашифрованное сохранение рекорда в локальный Vault |
| `clear_saved_vps` | — | `Result<(), String>` | Безопасное удаление сохраненных данных VPS с локального диска |
| `run_quick_ping` | `host`, `port?` | `Result<u64, String>` | Измерение текущей сетевой задержки до указанного порта в миллисекундах |
| `restart_service` | `service_name: String` | `Result<String, String>` | Мягкий перезапуск службы Xray или Hysteria 2 на сервере |
| `reboot_server` | — | `Result<String, String>` | Безопасная отправка команды перезагрузки операционной системы VPS |
| `regenerate_subscription_token` | — | `Result<String, String>` | Генерация криптографически стойкого 32-байтного hex-токена подписки |

### Защищенное локальное хранилище (Encrypted Vault)

Модуль `src-tauri/src/vault.rs` реализует шифрование данных VPS (IP, порт, токен подписки, URL) по стандарту **AES-256-GCM**:
- Ключ шифрования (32 байта) детерминированно вычисляется через SHA-256 на основе аппаратных данных текущего компьютера пользователя (`COMPUTERNAME`, `USERNAME`, `PROCESSOR_IDENTIFIER` и локальная соль).
- Для каждого сохранения генерируется криптографически стойкий случайный 12-байтный одноразовый вектор (Nonce) через `rand::thread_rng()`.
- Данные защищены от подделки и повреждения 16-байтным тегом аутентификации Poly1305.

## Матрица портов и фаервола (UFW)

Политика фаервола по умолчанию: **Входящий трафик запрещен (`DENY INCOMING`)**, исходящий разрешен (`ALLOW OUTGOING`).

| Порт | Протокол | Назначение / Служба | Защита и маскировка |
|---|---|---|---|
| **22** | TCP | SSH Server | Fail2ban (бан на 24ч при 4 ошибках) |
| **20443** | TCP | VLESS Reality XTLS-Vision | SNI: `addons.mozilla.org`, fallback: 443 |
| **2053** | TCP | VLESS Reality SplitHTTP (xhttp) | SNI: `addons.mozilla.org`, Anti-DPI Chunks |
| **8443** | TCP | VLESS Reality gRPC | SNI: `addons.mozilla.org`, service: `yabl1ch-grpc` |
| **2083** | UDP | Hysteria 2 (QUIC) | Salamander Auth, SNI: `addons.mozilla.org` |
| **2088** | TCP/UDP | Shadowsocks-2022 | Метод: `2022-blake3-aes-128-gcm` |
| **18080** | TCP | Votex Subscription Microservice | Секретный токенизированный путь `/sub/{TOKEN}` |

Все остальные входящие порты заблокированы фаерволом UFW.

## Сборка из исходников для разработчиков (Build from Source)

Если вы хотите собрать бинарники и инсталляторы Votex самостоятельно из исходного кода:

### Требования к окружению:
- **Node.js**: версия 20+ и пакетный менеджер **pnpm** (`npm install -g pnpm`).
- **Rust Toolchain**: версия 1.80+ (Rust 2021 Edition).
- **С-компилятор / линкер для Windows**: LLVM-MinGW (UCRT), GNU MinGW или MSVC C++ Build Tools.

### Инструкция по сборке:

```powershell
# 1. Клонировать репозиторий
git clone https://github.com/Yabl1ch/Votex.git
cd Votex

# 2. Установить зависимости фронтенда
pnpm install

# 3. Запуск приложения в режиме разработки (Hot-Reload)
pnpm tauri dev

# 4. Проверка типов TypeScript и сборка интерфейса
pnpm build

# 5. Оптимизированная релизная сборка бинарника и установщиков
pnpm tauri build
```

Собранные файлы будут размещены в:
- Портативный исполняемый файл: `src-tauri/target/release/votex.exe`
- Инсталлятор NSIS: `src-tauri/target/release/bundle/nsis/Votex_1.0.0_x64-setup.exe`
- Инсталлятор WiX MSI: `src-tauri/target/release/bundle/msi/Votex_1.0.0_x64_en-US.msi`
