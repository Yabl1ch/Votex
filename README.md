# Votex (Вотекс)

> **Votex** — Автоматизированный инструмент развертывания неуязвимого VPN на чистый VPS с многоуровневым харднингом, защитой от ботов и встроенной умной маршрутизацией (Smart Routing) для обхода блокировок РКН/ТСПУ.

---

## Архитектурные принципы

- **One-Click Hardening**: Полное закрытие неиспользуемых портов, перенос SSH, `fail2ban`, защита от брутфорса, оптимизация TCP BBR.
- **Next-Gen Протоколы**: VLESS Reality (XTLS-Vision / SplitHTTP xhttp / gRPC), Hysteria 2, Shadowsocks-2022.
- **Smart Routing (Умная маршрутизация)**: Автоматическое разделение трафика:
  - Российские сервисы, банки и госсайты (`.ru`, `.su`, Yandex, VK, Ozon, Gosuslugi) идут напрямую (**Direct**).
  - Заблокированные ресурсы и ИИ-сервисы (Gemini, Claude, OpenAI, YouTube) идут через зашифрованный туннель (**Proxy**).
  - Реклама, трекеры и торренты блокируются (**Block**).
- **TLS Fragmentation**: Фрагментация пакетов на уровне клиента для обхода DPI/ТСПУ.
- **Легковесный десктоп**: Приложение на базе **Tauri v2 + Rust + React/TypeScript** с фирменным интерфейсом **Organic Glass Bento UI**.
